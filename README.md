# Configuração do git

Configurar username e email:

```
git config --local user.name "utilizador Git"
git config --local user.email "email Git"
```

Adicionar o repositório de origem e pull 'main':

```
git remote add origin https://github.com/OWNER/REPOSITORY.git
git pull -u origin main
```
